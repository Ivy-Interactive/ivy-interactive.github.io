Ivy Tendril MCP Server

Connect Claude, ChatGPT, and custom orchestrators directly to Tendril's agentic execution engine.

Connection Options

1. Standard I/O (stdio)

tendril mcp

2. Streamable HTTP / Server-Sent Events

Endpoint: http://127.0.0.1:5010/mcp

Discovery manifest: /.well-known/mcp.json

Claude Desktop / Claude Code Configuration

{
  "mcpServers": {
    "tendril": {
      "command": "tendril",
      "args": ["mcp"]
    }
  }
}

Available Tools

ToolDescription
plan_listList all plans in active workspace filtered by status.
plan_getRetrieve complete plan details, annotations, and verification status.
plan_createCreate a new execution plan for an autonomous coding agent.
plan_runTrigger execution of an approved plan in an isolated git worktree.
worktree_listList all active isolated git worktrees.
verification_runRun automated compiler, linter, unit test, and visual verification gates.
