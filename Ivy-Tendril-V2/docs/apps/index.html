Apps

Explore the Tendril desktop applications for managing dashboards, reviews, plans, jobs, and pull requests.

Apps

Tendril provides specialized desktop apps and views designed for distinct phases of the software planning and execution [Plan Lifecycle](../02_Concepts/03_Lifecycle.md):

  • [Dashboard](01_Dashboard.md) — Operational overview featuring plan pipeline flow, KPI metrics with drill-down breakdown blades, 28-day daily trend, and active [Jobs](04_Jobs.md) monitors.
  • [Review](02_Review.md) — Decision queue for finished plans awaiting approval, verification logs, inline change requests, project review actions, and [GitHub](https://github.com) pull request creation.
  • [Plans](03_Plans.md) — Plan drafting and refinement workspace with multi-revision diffs, embedded chat, verification gates, and [Promptware](../02_Concepts/02_Promptwares.md) execution controls.
  • [Jobs](04_Jobs.md) — Execution monitor and audit log featuring live terminal output streaming, token/cost breakdowns, debug sheets, and process management.
  • [Icebox](05_Icebox.md) — Backlog staging area for deferred and on-hold plans with full-text search, project and level filtering, and one-click thawing into active [Plans](03_Plans.md).
  • [Pull Requests](06_PullRequests.md) — Cross-project tracking for [GitHub](https://github.com) pull requests with background status synchronization via the [GitHub CLI](https://cli.github.com), spend metrics, and follow-up plan generation.
  • [Recommendations](07_Recommendations.md) — Automated suggestions for codebase improvements and missing test coverage with one-click acceptance and [GitHub](https://github.com) issue creation.

    • For instructions on configuring projects and agents that feed these apps, see [Setup & Settings](../03_Configuration/01_Setup.md) and [Project Setup](../03_Configuration/02_Projects.md).
