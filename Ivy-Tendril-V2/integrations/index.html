Integrations

Connect Tendril with external tools and services to streamline your development workflow and automate [plan execution](../02_Concepts/01_Plans.md).

  • [GitHub](01_Github.md) — issue importing, automatic pull request creation, and PR status synchronization with [GitHub](https://github.com).
  • [Jam.dev](02_JamDev.md) — automated plan creation from bug reports via the [Jam.dev](https://jam.dev) inbox API webhook.
  • [OpenClaw](03_OpenClaw.md) — file-based plan ingestion from external tools like OpenClaw via the Tendril Inbox drop folder.
