Getting Started with Ivy Tendril

The Agentic Software Factory for 10x Builders. Run autonomous coding agents in parallel git worktrees with verification gates and human-in-the-loop plan supervision.

Quick 5-Step Setup Walkthrough

Step 1: Install Tendril Desktop App or CLI

Download the native desktop application for macOS (Apple Silicon / Intel), Linux (.AppImage, .deb), or Windows (.msi) from GitHub Releases, or install the CLI toolchain via Cargo:

# Install CLI toolchain via Cargo:
cargo install tendril-cli

# Run system health check and verify prerequisites:
tendril doctor

Step 2: Initialize Your Workspace & Projects

Tendril organizes repositories as Projects with isolated git worktrees so agents never modify your primary working tree without permission:

# Interactive onboarding wizard:
tendril onboarding

# Or register an existing git repository directly:
tendril project add /path/to/repository --name my-project

Step 3: Launch the Tendril Background Daemon

Tendril includes an Axum REST and WebSocket daemon that coordinates agent runs, tool calls, and real-time terminal output on port 5010:

# Launch background daemon:
tendril run

# Or launch in ephemeral sandbox mode for risk-free testing:
tendril run --sandbox

Step 4: Create and Execute Your First Plan

Tasks are modeled as structured Plans. Once approved, Tendril spins up an isolated worktree branch and starts your selected coding agent (Claude Code, OpenAI Codex, GitHub Copilot, OpenCode, or Google Gemini):

# Create a new plan:
tendril plan create "Implement user authentication with OAuth2 PKCE"

# Execute plan with Claude Code in an isolated worktree:
tendril plan run <plan-id> --agent claude-code

# Check verification gates (compiler, linter, tests, visual screenshots):
tendril verification run --plan <plan-id>

Step 5: Connect via Model Context Protocol (MCP)

Expose Tendril's plan and worktree tools to Claude Desktop, ChatGPT, or custom agent runners:

# Start standard I/O MCP server:
tendril mcp

# Streamable HTTP endpoint:
http://127.0.0.1:5010/mcp
